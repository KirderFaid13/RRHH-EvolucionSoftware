# Semana 09: gestión del cambio

La exposición actual utiliza una plataforma hipotética de entradas para explicar la teoría y, desde la página 16, presenta el caso práctico del RRHH. Duración orientativa: 25 min 20 s.

## Material actual de exposición

- [Presentación editable con teoría revisada](Semana09_Gestion_Cambio_RRHH_Teoria_Revisada.pptx): quince páginas de conceptos y ejemplos externos, seguidas de las once páginas prácticas conservadas.
- [Guion actualizado](06_guion_teoria_revisada.md): idea central, ejemplo, explicación y tiempo por página; preguntas para defender teoría y práctica.

La teoría explica qué se modifica, por qué se controla, los cuatro propósitos solicitados por el curso, ocho etapas, roles, impacto, aceptación, planificación, pruebas, publicación, reversión y trazabilidad. El ejemplo de transferir una entrada mantiene una credencial vigente y un único derecho de acceso. Es hipotético y supone validación en línea.

La corrección editorial responde a la [Issue #15](https://github.com/KirderFaid13/RRHH-EvolucionSoftware/issues/15). El [contrato](../../../specs/c07_revision_teoria.json) delimita su alcance y el [registro de revisión](../../../evidencia/semanas/semana09/revision_teoria.json) documenta la preservación y los hashes. Es una actualización documental de C07; no añade una semana ni otra implementación.
