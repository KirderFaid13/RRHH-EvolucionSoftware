# Documentación semanal

Cada mejora tendrá un directorio por semana y una explicación que incluya consigna, caso elegido, procedencia del código anterior, cambio, motivo, comprobaciones y límites. Los informes y diapositivas deben reflejar el trabajo realmente realizado.

Disponibles: [semana 04/v2 SRP y DRY](semana04/01_srp_dry.md), [semana 05/v3 OCP](semana05/01_ocp.md) y [semana 07/v4 IoC](semana07/01_ioc.md). Semana 07 muestra únicamente dependencia, mejora, composición y pruebas con sustitutos; su incorporación se documenta como quinto commit por PR y squash.

Los resultados se guardarán en [evidencia/semanas](../../evidencia/semanas/README.md). El [roadmap](../../.context/ROADMAP.md) indica el avance de cada etapa.
