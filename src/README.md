# Código recuperado y evolución

Esta carpeta conserva [v1 recuperada](v1/README.md), [v2 SRP/DRY](v2/README.md), [v3 OCP](v3/README.md) y [v4 IoC](v4/README.md), entrega del quinto commit. Cada compilación selecciona una sola fachada y reutiliza las fuentes anteriores indicadas por su README. Los antecedentes están separados del código activo.

La ubicación de la entrega original se describe en el [README del repositorio](../README.md). Se mantiene separada del código de esta carpeta para conservar la referencia contra la que se explicarán los cambios.

Al incorporar código, se documentará si procede de un archivo fuente original, de una descompilación, de una reconstrucción parcial o de una implementación propuesta. También se registrará qué se pudo compilar o ejecutar realmente.

Las siguientes etapas no deben reemplazar una recuperación incompleta por funciones inventadas ni presentar una propuesta como una copia fiel del sistema original. Consulta el [roadmap](../.context/ROADMAP.md) para el orden de incorporación.
