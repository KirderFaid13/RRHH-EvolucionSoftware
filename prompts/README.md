# Prompts de trabajo

Los prompts fijan el objetivo, las fuentes y los límites de una etapa. Pueden utilizarse con distintas herramientas y modelos; la elección de una herramienta no sustituye la comprobación del resultado.

El primer commit incluye únicamente el [prompt para la próxima etapa de ingeniería inversa](01_ingenieria_inversa.md). Su presencia es una preparación del trabajo: no acredita que la etapa ya se haya ejecutado.

Antes de usarlo, el equipo debe indicar que desea continuar después del primer commit. Los prompts de SRP/DRY, OCP e inversión de control se definirán cuando exista una base recuperada y un caso sustentado para cada mejora.

Cada ejecución debe terminar con una explicación del cambio, su ubicación, su motivo, las comprobaciones realizadas y las limitaciones pendientes. El orden completo se encuentra en el [roadmap](../.context/ROADMAP.md).
